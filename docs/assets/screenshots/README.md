# Screenshot & Media Directory

This directory contains interface previews, diagrams, and screenshots for `tak-p2p`.

## Current Screenshot Previews (Vector SVG)
* `web-board.svg`: Zero-install Blazor WebAssembly client interface.
* `desktop-avalonia.svg`: Avalonia UI native desktop client on Windows, Linux, and macOS.
* `cli-ansi.svg`: Spectre.Console ANSI terminal board and stack inspector.
* `mobile-board.svg`: Mobile PWA touch experience on iPhone (iOS Safari) and Android (Chrome).

## Replacing with Real Screenshots
When capturing real application screenshots:
1. **Desktop / Web Screenshots:** Recommended resolution: `1600x960` or `1920x1080` (16:10 or 16:9), PNG format.
2. **Terminal CLI:** Recommended 80x24 or 100x30 ANSI character frame, captured in Windows Terminal or Linux terminal with high DPI.
3. **Mobile Screen:** Recommended `750x1334` or `1170x2532` (iPhone/Android portrait).
